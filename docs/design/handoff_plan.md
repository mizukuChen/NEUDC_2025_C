# 项目交接与后续规划

## 1. 项目目标

本项目面向 2025 年全国大学生电子设计竞赛 C 题“基于单目视觉的目标物测量装置”，目标是在树莓派上使用单个摄像头完成目标物距离 `D` 和纸面图形尺寸 `x` 的测量，并最终集成按键、显示、电流采样和功耗计算。

题目核心限制：

- 只能使用一个摄像头。
- 不得使用超声、激光、毫米波雷达等非视觉测距方式。
- 测量装置不得使用 PC 机参与测试。
- 一键启动后需要在 5 秒内显示结果。
- 基本题 `D` 误差要求不超过 `5 cm`，`x` 误差要求不超过 `1 cm`。
- 发挥题 `D` 误差要求不超过 `2 cm`，正方形边长 `x` 误差要求不超过 `0.5 cm`。

## 3. 总体技术路线

整体算法先分成两个阶段：

### 阶段 A：定位目标纸面

输入为摄像头原始图像，输出为 A4 纸四角点和标准正视纸面图像。

主要任务：

- 检测目标物四周黑色边框。
- 提取黑框对应的四边形区域。
- 得到四个角点，按左上、右上、右下、左下排序。
- 对目标纸面做透视矫正，输出固定尺寸的标准 A4 图。
- 后续可基于四角点做 `solvePnP`，估计目标物相对摄像头的姿态和距离。

注意事项：

- 普通题中目标物基本正对摄像头，只存在小角度误差，可以先按正对场景调参。
- 发挥部分最后一题存在 `30°~60°` 大角度斜放，不能依赖原图中的长宽比，需要严格使用四角点透视矫正。
- 第一阶段尽量只依赖黑框，不依赖纸面内部图形，保证基本题和发挥题可复用。

### 阶段 B：识别纸面图形

输入为透视矫正后的标准 A4 图，输出为图形类型和尺寸 `x`。

主要任务：

- 去掉四周黑边框和底部中点标记点。
- 在纸面内部检测黑色实心图形。
- 基本题识别圆形、等边三角形、正方形。
- 根据标准 A4 图像比例，把像素尺寸换算为毫米或厘米。
- 发挥题继续扩展多个正方形、重叠正方形、带编号正方形。

建议标准 A4 图尺寸：

```text
2100 x 2970 px
```

这样换算关系为：

```text
10 px = 1 mm
```

## 4. 开发策略

建议先用手机拍摄的清晰照片验证算法主链路，再迁移到树莓派摄像头图像。

推荐数据目录：

```text
runtime/captures/phone/    手机拍摄的调试图
runtime/captures/rpi/      树莓派摄像头拍摄的真实图
```

手机照片阶段用于验证：

- 黑框是否能稳定检测。
- 透视矫正是否正确。
- 基本图形能否识别。
- 尺寸换算是否合理。

树莓派照片阶段用于适配：

- 摄像头分辨率。
- 镜头畸变。
- 曝光、白平衡、噪声。
- 阈值和轮廓筛选参数。
- 实际比赛装置的相机高度和视角。

## 5. 下一步任务

### 任务 1：准备离线测试图片

拍摄基础题靶标照片，先使用手机即可：

```text
runtime/captures/phone/basic_circle_01.jpg
runtime/captures/phone/basic_triangle_01.jpg
runtime/captures/phone/basic_square_01.jpg
```

要求：

- A4 纸完整入镜。
- 黑框清晰。
- 背景尽量简单。
- 先不要故意大角度倾斜。

### 任务 2：实现黑框检测

新增文件建议：

```text
src/vision/target_plane.py
```

职责：

- 读取原始图像。
- 灰度化和阈值分割黑色区域。
- 查找候选轮廓。
- 筛选最大、稳定、接近四边形的黑框区域。
- 输出四角点。
- 保存带角点标注的调试图。

### 任务 3：实现透视矫正

新增文件建议：

```text
src/vision/rectify.py
```

职责：

- 输入原图和 A4 四角点。
- 输出 `2100 x 2970 px` 标准 A4 正视图。
- 保存矫正后的调试图。

### 任务 4：实现基本图形测量

新增文件建议：

```text
src/vision/measure_basic.py
```

职责：

- 输入标准 A4 图。
- 裁掉黑边框和底部标记点。
- 检测内部黑色图形轮廓。
- 判断圆形、三角形、正方形。
- 输出 `shape_type` 和 `x_mm`。

### 任务 5：实现命令行测试入口

新增脚本建议：

```text
scripts/run_basic_measure.py
```

用法目标：

```powershell
python scripts/run_basic_measure.py runtime/captures/phone/basic_square_01.jpg
```

输出内容：

- 是否成功找到 A4 纸面。
- 图形类型。
- 测得尺寸 `x_mm`。
- 调试图输出路径。

### 任务 6：接入树莓派拍照

在离线脚本稳定后，再把 `src/camera_test.py` 扩展为正式采集模块，或新增：

```text
src/capture.py
```

职责：

- 固定摄像头分辨率。
- 尽量锁定曝光和白平衡。
- 拍照保存到 `runtime/captures/rpi/`。
- 调用视觉算法。

### 任务 7：距离 D 测量

先做快速版本：

- 在目标物近似正对时，用 A4 纸成像高度或宽度估算距离。
- 通过实测几个距离点拟合比例或标定曲线。

再做稳定版本：

- 相机标定得到内参和畸变参数。
- 使用 A4 四角点和实际尺寸做 `solvePnP`。
- 根据相机安装位置、目标物标记点和基准线位置换算题目定义的 `D`。

### 任务 8：硬件与发挥题

基本题闭环后再做：

- GPIO 按键触发。
- OLED/LCD 显示。
- 自制电流采样电路和 ADC 读取。
- 功耗 `P = 5V * Is` 和最大功耗 `Pmax`。
- 多正方形、编号识别、斜放目标物处理。

## 6. 当前优先级

最高优先级是先完成离线图像识别闭环：

```text
照片 -> 黑框四角 -> 透视矫正 -> 基本图形识别 -> x 尺寸
```

暂时不要同时推进按键、显示、电流采样。视觉链路稳定后，再接树莓派硬件会更稳。

## 7. 交接注意事项

- Windows 环境可以继续开发，不依赖 WSL。
- 代码中路径应使用 `pathlib.Path`，避免写死 Windows 或 Linux 路径。
- 先保留手机照片和树莓派照片两套数据，便于区分算法问题和设备图像问题。
- 不要把第一阶段黑框检测写成只支持水平矩形，至少应保留四角点输出，方便后续处理斜放题。
- 对发挥题最后一项，必须使用透视矫正或姿态估计，不能只按原图外接矩形测量。
